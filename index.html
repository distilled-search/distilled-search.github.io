Abstract

Despite recent advances in policy learning, long-horizon manipulation remains difficult because learned policies must avoid compounding errors while preserving future feasibility. While search-based planning can explicitly reason over such future consequences, it quickly becomes expensive in high-dimensional continuous action spaces. This raises a central question:

How can long-horizon reasoning from search be transferred into policies in continuous action spaces?

To this end, we propose DISCO: Distilled Tree Search over Continuous Actions. DISCO uses progressive-widening MCTS in physics simulation to generate long-horizon plans. During search, a learned policy proposes continuous actions, while a learned value function scores actions by their expected progress toward task completion. Using GPU-parallelized simulation, DISCO periodically distills MCTS-generated plans into the policy-value model, improving the action proposals and value estimates used in subsequent searches. Finally, the learned policy value model can be directly deployed without the need for simulator-based search at test time. Across simulated and real-world rearrangement tasks, DISCO out performs behavior cloning, reinforcement learning, and search-based baselines.

How DISCO Works

DISCO uses Monte-Carlo Tree Search with a learned policy and value function. It uses progressive widening to explore the continuous state-action space, and iteratively distills the discovered long-horizon reasoning into the policy and value models. Each step of the algorithm is visualized below.

Simulation Tasks

Pack every object into a shelf of random size without anything falling out. DISCO may nudge objects already inside to make room.

  • 2–7 objects
  • Budget β = 270,000 simulator calls
  • 50 training · 15 test scenes
  • Pre-trained on 1,776 single-step demos
  • Reward: fraction of objects in the shelf

Stack objects of very different shapes into one stable tower, without knocking any off.

  • 2–6 objects
  • Budget β = 27,000 simulator calls
  • 50 training · 15 test scenes
  • Pre-trained on 1,776 single-step demos
  • Reward: fraction of objects in the tower

Multi-Modality

One task, more than one way to solve it. Because DISCO distills many plans found by search, its policy keeps several solution strategies instead of averaging them away.

Real World Execution

Transferred sim-to-real with no fine-tuning. DISCO against the 3DFA baseline, trained on the same sub-task demos, over three trials each.

Why 3DFA? It is the same policy architecture DISCO distills into, so the comparison isolates the effect of DISCO's search-and-distill self-improvement loop.
